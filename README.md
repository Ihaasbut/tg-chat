# Telegram

Браузерный чат с Telegram через GREEN-API.

## GREEN-API

1. Зарегистрируйтесь в [личном кабинете GREEN-API](https://console.green-api.com/).
2. Создайте инстанс для Telegram и авторизуйте в нём свой аккаунт.
3. Скопируйте со страницы инстанса `apiUrl`, `idInstance` и `apiTokenInstance`.
4. В настройках инстанса оставьте `webhookUrl` пустым и включите входящие уведомления (`incomingWebhook`).

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте в браузере адрес, который покажет Vite, обычно `http://localhost:5173`.

## Как пользоваться

1. Введите адрес API, ID инстанса и API-токен.
2. Введите номер собеседника в международном формате, без `+`: `79991234567`.
3. Нажмите «Начать чат» и отправьте сообщение.
4. Ответьте с другого Telegram-аккаунта — ответ появится в чате сам.
